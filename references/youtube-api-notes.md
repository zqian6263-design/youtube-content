# YouTube API Notes

## Caption / Transcript Access

This skill uses `youtube-transcript-api` (no API key required) to fetch
subtitles. YouTube provides two types of captions:

1. **Manual captions** — uploaded by the video creator (high quality)
2. **Auto-generated captions** — generated by YouTube's ASR (variable quality)

The script prefers manual captions first, falling back to auto-generated.

### Language handling

- `--languages zh-Hans,zh-Hant,en` — tries Simplified Chinese first,
  then Traditional Chinese, then English.
- YouTube uses IETF language tags (zh-Hans, zh-Hant, en, ja, ko, etc.)

## Audio Download

Uses `yt-dlp` to download the best available audio stream, then converts
to 16kHz mono WAV via ffmpeg for Whisper transcription.

## Known Limitations

- Some videos have captions disabled entirely
- Auto-generated captions may have inaccurate timing/text
- Very long videos (>3h) may timeout during Whisper transcription
- Age-restricted videos may fail to download
- Member-only / paid content is not accessible

## Comparison: YouTube vs Bilibili Content

| Aspect | YouTube | Bilibili |
|--------|---------|----------|
| Caption auth | Public (no cookies needed) | Requires login cookies |
| Caption quality | Manual + auto-generated | Mostly AI-generated |
| Audio download | yt-dlp | Bilibili playurl API |
| Multi-video | Playlist support (future) | Multi-P episodes |
| Rate limiting | Moderate | Aggressive |
